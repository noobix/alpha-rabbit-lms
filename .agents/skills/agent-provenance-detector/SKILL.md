# Agent Provenance Detector

Detects likely coding agents used to generate or assist with source files and provides evidence and confidence scores.

## When to Use This Skill

- When preparing per-file implementation notes documenting authorship and provenance.
- When a pre-commit or CI check must determine whether an automated agent contributed to changes.

## Trigger Phrases / Examples

- "Detect whether this file was generated by Copilot or another agent"
- "Run provenance detection on staged files before commit"
- "Append agent author metadata if an LLM produced this code"

## Install / Run

This skill is implemented as a lightweight Python script in `scripts/`.

Run locally:

```
python scripts/detect_agent_provenance.py path/to/file.py
```

Or run in batch for staged files from the appender script (used by the pre-commit hook):

```
python scripts/append_provenance.py
```

## Detection Heuristics (summary)

- Look for explicit metadata or comments: `Generated by`, `LLM-assisted`, `copilot`, `assistant`, `model:`
- Inspect YAML front-matter `author:` or `generated-by:` keys
- Check for repository prompt references (e.g., `.github/prompts/` patterns) or prompt IDs
- Provide a confidence score proportional to matched evidence count and pattern strength

## Privacy & Notes

- The detector returns minimal evidence strings (no raw prompts). Avoid storing prompts centrally.
- This skill is intentionally heuristic-first; it can be extended with statistical or watermark detectors later.
